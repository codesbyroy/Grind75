# DSA Learning Log

A personal record of deliberate data structures and algorithms practice in Java. The goal is to build problem-solving fluency and retain useful patterns.

## How to use this log

Each solved problem has a folder under `problems/` containing:

- `Solution.java` - the implementation and small local examples.
- `README.md` - the problem link, core idea, complexity, and a short reflection on what to remember or revisit.

When adding an entry, write the explanation in your own words. Capture the decision that led to the approach, a mistake or edge case worth remembering, and whether the problem needs another review. Keep source comments focused on non-obvious decisions.
